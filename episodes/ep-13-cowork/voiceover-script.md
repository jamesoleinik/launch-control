# Episode 13 voice-over: extend the scenario with agents

**Status:** Untimed draft for the combined declarative-agent and Copilot Studio
episode. No new build or runtime outcome is verified by this copy. The
90-120-second production brief applies to Episode 12; Episode 13's final
length and editions remain to be set.

| Shot | Spoken copy |
|---|---|
| Open on the same Launch Control record from the Chat/Cowork episode. | I can already ask Copilot about my launch. Now I want to make that job repeatable with a focused agent. |
| Show the declarative agent's actual instructions and selected app knowledge. | I give the declarative agent a clear purpose and the right business source. It should explain recorded blockers and tell me when evidence is missing. |
| Show a fresh answer and the source comparison. | I test the agent against the app. A useful answer needs evidence, not an invented readiness approval. |
| Open the separately configured Copilot Studio agent. | I use Copilot Studio when I want more control over the steps and integrations. I verify its connection instead of assuming the other experience carries over. |
| Show the bounded retrieval and follow-up proposal. | I ask for a follow-up plan based on fresh records. The proposal stays separate from saving tasks or sending messages. |
| Close on the source record and the actual configurations. | I can choose the agent experience that fits the job. The standard stays the same: clear scope and evidence I can verify. |
